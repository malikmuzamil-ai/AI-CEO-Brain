Step-by-step installation guide

1

Download the plugin zip from Google Drive

Open the Drive folder, find ai-ceo-brain.zip, and download it to your computer. Keep it as a zip file. Do not unzip it.

↗ Open Google Drive folder
2

Open Claude Cowork and go to Customize

Open Claude Cowork on desktop. Click the Customize button in the top right corner of the interface.

3

Open Personal Plugins and click the + button

Inside Customize, find the Personal plugins section. Click the + button to add a new plugin.

You are looking for Personal plugins, not the general Skills tab. The + button sits next to the Personal plugins heading.
4

Select Create plugin then Upload plugin

A menu appears with options. Click Create plugin, then on the next screen click Upload plugin. Select the ai-ceo-brain.zip file you downloaded. The plugin validates and installs automatically. You will see AI CEO Brain appear in your Personal plugins list.

Keep the file as a zip. Do not unzip it before uploading. If validation fails, re-download from the Drive folder and try again.
5

Connect your five services

Start a new conversation in Claude Cowork and type the connect command. This walks you through authorising each service one at a time via OAuth popups.

/connect-services
Services to connect: Google Drive, Gmail, Google Calendar, Notion, Apify. Each one takes about 30 seconds. You only do this once.
6

Authorise each service when prompted

For each service, Claude will trigger a small test query which opens the OAuth authorisation popup. Click Allow and return to the conversation. Claude confirms each one before moving to the next.

For Notion: select your main workspace and grant full page access. For Gmail: grant both read and send permissions so the pipeline agent can draft and send follow-ups.
7

Run the preflight check

Once all five services are connected, run the preflight check. This verifies all 17 skills, 10 agents, and 5 connectors are working correctly before you start.

/preflight-check
Any item showing a red cross gets a one-line fix in the report. Green ticks across the board means you are ready.
8

Start your first session

Type the monday prep command to pre-load your week, then say "Monday session" to run your first CEO session. Or just ask any business question to see a skill activate.

/monday-prep
